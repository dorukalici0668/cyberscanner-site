CYBER SCANNER

Yetkilinin size verdigi keyi girin. Key dogrulanirsa indirme otomatik baslar.

  1. Indirilen CheatScanner.exe'yi calistirin
  2. Windows mavi SmartScreen uyarisi cikarsa: Daha fazla bilgi > Yine de calistir
  3. Acilan ekrana AYNI keyi tekrar girin
  4. Tarama bitene kadar siyah konsol penceresini kapatmayin

Bu sayfa GitHub uzerinde barindirilir ve her zaman aciktir. Program yalnizca hile yazilimi izleri tarar.
