GITHUB MODU

Yerel sunucu bulunamadi. GitHub token'ini gir - key dogrudan GitHub uzerinden uretilecek (sunucuya gerek yok). Token yalnizca bu tarayicida saklanir.

Token'in yok mu? 30 saniyede olustur:
  1. Asagidaki linke tikla (ayarlar otomatik hazir):
    github.com/settings/tokens/new?scopes=repo
  2. Sayfanin altindaki yesil Generate token butonuna bas
  3. Cikan ghp_... kodunu kopyala ve buraya yapistir

Butona bas, kodun hazir - kopyala ve gonder.
